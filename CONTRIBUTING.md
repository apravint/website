# Contributing

Thanks for your interest in improving this site. Bug reports, accessibility fixes and small improvements are welcome.

## Getting started

Requires Node.js 22 (see `.nvmrc`).

```bash
npm ci
npm run dev        # http://localhost:3000
```

## Before opening a pull request

Run the same checks CI runs:

```bash
npm run lint
npm run typecheck
npm test
npm run build      # static export to ./out
```

- Add or update tests in `tests/` for behaviour you change. Component tests use Vitest and Testing Library, and include an axe accessibility check.
- Keep interactive elements keyboard-accessible and labelled; `eslint-plugin-jsx-a11y` runs as part of `npm run lint`.
- Keep pull requests focused. Describe what changed and why.
- Do not edit `docs/` or `android/` by hand; they are generated by the build and by `npx cap sync`.

## Reporting bugs and ideas

Open an issue using one of the templates. For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
