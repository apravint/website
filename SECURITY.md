# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues or pull requests.

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. If that is unavailable, email apravint@gmail.com with a description, steps to reproduce and the affected page or version.

You can expect an acknowledgement within a few days. Fixes are released as soon as practical, and you will be credited if you wish.

## Scope

This repository is a statically exported Next.js website and a Capacitor Android wrapper. It has no server-side component and stores no user accounts. Reports about the build, dependencies, the Android wrapper, or client-side behaviour are in scope.
