# Code of conduct

Be respectful and constructive. Harassment, personal attacks and discriminatory language are not acceptable in issues, pull requests or any other project space.

Maintainers may edit or remove contributions that break these rules. To report a problem, email apravint@gmail.com.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
